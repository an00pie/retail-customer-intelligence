Technical FAQ & Platform Architecture
Retail businesses struggle with massive unstructured transactional logs where identifying top customers, predicting future spend, and preventing customer churn is slow and fragmented. This platform provides an end-to-end Big Data pipeline from web mining to HDFS, Hive, Spark ML, and a high-performance columnar KV serving layer for automated decision-making.
Analytical warehouse systems like Hive are optimized for large batch scans, not real-time lookups. For production serving, the platform utilizes an embedded columnar Key-Value store following Apache HBase column-family design (info:, pred:, meta:) with HappyBase interface compatibility, providing direct, indexed point lookups for 5,942 profiles.
Unsupervised K-Means clustering (k=4) groups 5,942 customers into distinct cohorts: Champions (high spend & frequency), Loyal Customers (steady orders), At-Risk (high past spend but inactive), and Lost / Churned (dormant single purchases). Segment mappings are verified in models/segment_mapping.json.
